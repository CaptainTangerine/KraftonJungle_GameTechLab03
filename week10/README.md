> DirectX 11 에디터에 FBX 정적·스켈레탈 메시 가져오기와 3D 미리보기 기능을 확장했습니다.

## 프로젝트 개요

이전 주차까지 구축한 엔진과 에디터에 FBX SDK 기반 에셋 파이프라인을 추가했습니다. FBX의 노드 계층, 정적 메시, 스켈레탈 메시, 본과 재질 정보를 읽어 엔진의 메시 데이터로 변환하고, 에디터의 독립된 프리뷰 화면에서 확인·배치할 수 있도록 했습니다.

## 팀 전체 구현

- FBX 정적·스켈레탈 메시 가져오기, 노드 계층과 재질 슬롯 처리
- 본 계층과 가중치를 활용한 스켈레탈 메시 렌더링 및 미리보기
- 스켈레탈 메시 액터·컴포넌트, 에셋 캐시와 씬 직렬화·복원
- FBX 프리뷰의 카메라·기즈모·다중 화면 편집 기능

## 개인 기여

### FBX 지오메트리 가져오기

- FBX SDK에서 읽은 노드를 엔진의 정적·스켈레탈 메시 데이터로 변환했습니다. 정점 위치·법선·UV·탄젠트, 인덱스, 섹션과 재질 슬롯을 구성하고, 원본 컨트롤 포인트 인덱스를 보존해 본 가중치와 연결했습니다.
- 컨트롤 포인트와 위치·법선·UV 조합을 기준으로 정점을 재사용하도록 했습니다. 메시 좌표는 로컬 공간에 두고 노드 변환은 한 번 적용했으며, 비균등 스케일의 법선에는 역전치 변환을 적용했습니다.
- 같은 스켈레톤 루트에 속한 스킨 메시를 묶고, 여러 정적 메시를 하나의 메시로 합칠 때 정점·인덱스 오프셋과 재질 슬롯·섹션 인덱스를 다시 계산했습니다. 원본 노드 변환을 합쳐진 메시의 로컬 공간으로 옮겨 배치가 어긋나지 않도록 했습니다.

### CPU 스키닝과 렌더링 연동

- FBX의 본 계층과 역바인드 변환, 정점별 본 가중치를 가져왔습니다. 정점당 최대 4개 영향 본을 선택하고 가중치를 정규화했습니다.
- 부모 본의 인덱스 순서를 가정하지 않도록 DFS로 현재 본의 전역 변환을 계산했습니다. 역바인드 변환과 현재 변환을 조합해 정점 위치·법선·탄젠트를 가중 합산하는 CPU 스키닝을 구현했습니다.
- 스킨 메시의 렌더 리소스를 수집 단계에서 준비하고, 일반 렌더링·그림자·선택 오버레이가 같은 메시 버퍼를 사용하도록 연결했습니다. 패스마다 바인드 포즈를 다시 초기화해 프레임이 떨어지는 문제도 수정했습니다.

### 에디터 FBX 미리보기

- FBX 전용 프리뷰 월드와 뷰포트 클라이언트를 에디터 렌더 파이프라인에 연결했습니다. 별도 렌더 타깃의 결과를 ImGui 이미지로 표시하고 마우스 입력을 프리뷰 카메라·선택 처리에 전달했습니다.
- 노드 트리와 메시 통계, 그리드·축·조명 모드·외곽선 및 선택 오버레이를 프리뷰에 연결했습니다. 정적 메시 선택 시 기즈모가 해당 컴포넌트를 따라가도록 보완했습니다.
- FBX 파일 열기·프리뷰 재생성 과정의 크래시와 SDK·그리드의 반복 초기화를 수정했습니다. 빈 공간에서 액터를 생성할 때는 카메라 앞의 일정 거리를 사용하도록 개선했습니다.

## 문제 → 적용 방법 → 결과 → 개선 방향

| 문제 | 적용 방법 | 결과 | 개선 방향 |
|---|---|---|---|
| FBX 노드와 메시의 변환이 겹쳐 크기·방향이 틀어짐 | 메시 로컬 좌표 유지, 노드 변환 분리, 법선 역전치 변환 | 정적·스켈레탈 메시의 배치와 조명 계산을 일관되게 처리 | 다양한 FBX 좌표계와 비균등 스케일 사례 자동 검증 |
| 스켈레탈 메시가 바인드 포즈로만 표시됨 | 본 계층 순회, 역바인드 행렬과 최대 4개 가중치의 CPU 스키닝 | 본 변환에 따라 정점이 갱신되는 렌더 경로 구성 | 애니메이션 클립 재생과 GPU 스키닝 확장 |
| 여러 메시가 들어 있는 FBX가 지나치게 많은 컴포넌트로 분리됨 | 스켈레톤 루트별 그룹화와 정적 메시 병합 | 씬을 한 개의 정적 또는 스켈레탈 메시 단위로 다루기 쉬워짐 | 병합 전 원본 노드 정보의 편집·복원 범위 확대 |
| 스킨 메시를 여러 렌더 패스에서 반복 준비해 프레임이 하락함 | 수집 단계에서 메시 리소스를 한 번 준비 | 본 화면·그림자·오버레이가 준비된 버퍼를 공유 | 메시 변경 범위에 따른 부분 갱신 |

## 빌드와 실행

Windows에서 Visual Studio 2022 C++ 워크로드, Windows SDK, MSVC v143을 사용해 `Project/NipsEngine.sln`을 `Release | x64`로 빌드합니다. 프로젝트에 포함된 FBX SDK·FMOD 라이브러리와 NuGet 패키지를 사용합니다. 실행 시 작업 디렉터리는 `Project/NipsEngine`으로 설정해야 상대 경로의 에셋을 찾을 수 있습니다.

## 회고

FBX 파일을 읽는 작업은 파싱만으로 끝나지 않았습니다. 노드와 메시의 좌표 공간, 본 계층, 재질 슬롯, 렌더 패스가 서로 맞아야 에디터에서 같은 모델을 안정적으로 확인할 수 있었습니다. 가져오기와 미리보기를 연결하면서 데이터 구조와 렌더 경로를 함께 설계하는 경험을 했습니다.
