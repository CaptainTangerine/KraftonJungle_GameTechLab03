## 기록 원칙

- 팀 프로젝트의 전체 결과와 개인 기여를 구분합니다.
- 다른 사람이 소유한 저장소는 코드를 복사하지 않고 원본 링크와 소유자를 표시합니다.
- 개인 기여는 가능한 경우 커밋, Pull Request, 영상 또는 실행 결과로 근거를 남깁니다.
- 비공개 원본은 공개 가능한 범위만 기록하고 `🔒`로 표시합니다.
