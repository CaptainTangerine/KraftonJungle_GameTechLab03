## 프로젝트 개요

GOInc는 물리 기반 래그돌을 찾아 빔으로 끌어와 수거하고, 제한 시간과 서버 과부하를 관리하는 1인칭 게임입니다. 팀은 타이틀·플레이·결과 화면, 래그돌 스폰과 미션·점수, 맵·UI·사운드를 연결했습니다. 개인적으로는 플레이어의 무기 조작과 물리 빔, 타격 피드백 및 게임 상태 연동을 중심으로 작업했습니다.

## 팀 전체 구현

- 타이틀·플레이·결과 씬과 GameMode, Lua 기반 게임 진행
- 래그돌 스폰·행동, 수거 포털, 미션·점수와 서버 과부하 규칙
- 1인칭 무기, 물리 상호작용, 전투 피드백과 맵 충돌
- HUD·메뉴·사운드·파티클 및 게임용 에셋·레벨 구성

## 개인 기여

### 1인칭 무기와 물리 빔

- 1인칭 ViewModel과 무기 피벗을 구성해 카메라 움직임에 따라 총과 총구가 자연스럽게 따라가도록 했습니다. 수거 빔과 공격 빔의 시작점을 총구에 붙이고 조준 방향에 맞춰 파티클의 시작·끝 위치를 갱신했습니다.
- 화면 중앙 Raycast로 잡을 물리 바디를 선택하고, 목표 위치와 실제 바디 위치의 오차에 스프링 힘·감쇠를 적용해 래그돌을 끌어오도록 했습니다. 질량에 따른 힘 보정, 마우스 휠 거리 조절, 던지기와 회전 토크도 연결했습니다.
- 물리 바디를 집을 때 캐릭터 캡슐이 본 바디를 가리는 문제에 대응해 잡기 전용 Raycast에서 스켈레탈 바디와 정적 메시 바디를 선별했습니다. 빔이 한 프레임 늦게 따라오는 현상은 카메라·Lua·파티클 갱신 순서를 조정해 해결했습니다.

### 피격·조준 피드백

- 집을 수 있는 물체에 Rim Light와 타격 지점 글로우를 적용하고, 빔을 유지하는 동안 외곽선이 이어지도록 했습니다. 두 무기 모드의 색과 효과를 구분하고 조준선의 중복 표시 및 크기를 보정했습니다.
- 공격 빔의 명중 방향을 래그돌에 전달해 질량에 비례한 넉백을 적용했습니다. 공격 시 카메라 셰이크, 총구 빔·먼지 파티클과 효과음을 더해 타격감을 보완했습니다.
- 조준 대상의 이름·무게·점수 정보를 HUD에 전달하고, 무기 교체·달리기와 시점 조작을 플레이어 입력에 연결했습니다.

### 레벨과 게임 상태 연결

- 서버룸을 중심으로 맵 에셋과 배치를 추가하고, 플레이어 루트의 캡슐과 Sweep 기반 이동으로 지형 충돌을 다듬었습니다. Sky Sphere의 이미지와 표시 옵션도 연결했습니다.
- 수거가 성공했을 때 서버 과부하를 낮추는 규칙을 연동하고, 수집한 ID 카드 정보를 세션에 기록해 다음 화면으로 전달했습니다. 카드 선택 시 외곽선·파티클·사운드 피드백을 추가했습니다.

## 문제 → 적용 방법 → 결과 → 개선 방향

| 문제 | 적용 방법 | 결과 | 개선 방향 |
|---|---|---|---|
| 래그돌을 직접 이동시키면 물리 반응이 어색하고 질량 차이가 드러나지 않음 | Raycast로 바디 선택, 위치 오차의 스프링·감쇠 힘과 질량별 보정 | 빔으로 물체를 끌고 거리·방향을 조작하는 수거 무기 구성 | 다양한 질량·프레임 조건에서 힘과 토크 튜닝 |
| 캐릭터 캡슐이 물리 바디보다 먼저 선택되거나 빔이 화면을 한 프레임 늦게 따라옴 | 잡기 대상 필터와 카메라·Lua·파티클 갱신 순서 조정 | 본 바디 선택과 총구–조준점 빔 위치를 일치시킴 | 입력·물리·렌더 갱신 시점의 회귀 사례 추가 |
| 수거·공격 모드의 대상과 명중 여부가 눈에 잘 띄지 않음 | Rim Light, 타격 지점 글로우, 파티클·카메라 셰이크·HUD 연동 | 조준 대상과 두 무기 모드의 피드백을 구분 | 화면 효과 강도와 접근성 옵션 조정 |
| 수거 결과와 수집 정보가 다음 게임 화면에 이어지지 않음 | 서버 부하 감소 규칙 및 GameSession의 카드 정보 연결 | 플레이 결과에 수거 보상과 수집 기록 반영 | 세션 전환·재시작 시 데이터 초기화 범위 점검 |

## 빌드와 실행

Windows에서 Visual Studio 2022 C++ 워크로드, Windows SDK, MSVC v143으로 `Project/KraftonEngine.sln`의 `Game | x64` 구성을 빌드합니다. `Project/GameBuild.bat`은 게임 빌드와 리소스 패키징용 스크립트입니다. 프로젝트에 포함된 PhysX·NvCloth·FBX SDK·FMOD 등 서드파티 의존성이 필요합니다. 에디터에서 실행할 때는 작업 디렉터리를 `Project/KraftonEngine`으로 설정합니다.

## 기술 스택

C++, Lua, DirectX 11, HLSL, PhysX, RmlUi, ImGui, FMOD

## 회고

물리 기반 무기는 화면의 빔만 맞춰서는 완성되지 않았습니다. Raycast가 어떤 바디를 선택하는지, 실제 힘이 질량과 충돌에 어떻게 반응하는지, 카메라와 파티클이 같은 프레임의 조준점을 쓰는지까지 연결해야 조작감이 만들어졌습니다. 팀의 미션·HUD 흐름에 무기 상태와 수거 결과를 이어 보며 엔진 기능을 게임 규칙으로 바꾸는 경험을 했습니다.
