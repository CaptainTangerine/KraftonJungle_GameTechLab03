# 🎞️ Week 11 — Skeletal Animation & GPU Skinning

> 스켈레탈 애니메이션 편집과 렌더링을 확장하고, CPU·GPU 스키닝을 비교하며 FBX 본 계층 문제를 해결했습니다.

## 프로젝트 개요

이전 주차의 FBX 스켈레탈 메시 파이프라인을 애니메이션 재생·편집까지 확장했습니다. 본 변환과 스킨 행렬을 CPU 또는 GPU에서 처리할 수 있게 하고, 메시 에디터에서 본 가중치·재생 상태를 확인하며, 애니메이션 Notify를 게임플레이 동작에 연결했습니다.

## 팀 전체 구현

- 애니메이션 시퀀스·몽타주·Notify 편집과 재생, 스켈레톤 호환성 처리
- GPU 스키닝·모프 타깃 및 메시 에디터의 본·가중치 시각화
- FBX 애셋 가져오기·재가져오기, 에셋 직렬화와 리플렉션 확장
- 캐릭터 시연 씬과 에디터 편집 기능

## 개인 기여

### GPU 스키닝과 렌더 경로

- 정적 메시와 스켈레탈 메시의 버텍스 셰이더를 분리하고, 조명 방식·버텍스 팩토리별 셰이더 순열 키를 구성했습니다. 본 행렬을 Structured Buffer로 버텍스 셰이더에 전달해 가중치 기반 GPU 스키닝을 구현했습니다.
- CPU·GPU 스키닝 모드를 콘솔에서 전환하고, 여러 뷰포트와 그림자 패스가 같은 전역 모드를 사용하도록 정리했습니다. 스켈레탈 그림자 전용 셰이더 경로와 가중치가 없는 정점의 원본 위치 처리도 추가했습니다.
- 렌더 파이프라인과 에셋 에디터 종료 시 DirectX COM 리소스를 정리해 누수를 수정했습니다.

### 스키닝 관찰 도구

- CPU 정점 스키닝, GPU 본 행렬 업로드와 PreDepth 패스의 시간을 표시하는 오버레이를 만들었습니다. 본 인덱스를 선택하면 해당 본의 정점 가중치를 색으로 표시하는 히트맵도 구현했습니다.
- FBX 가져오기 시간을 메시 에디터에 표시해 임포트 비용을 확인할 수 있게 했습니다. Content Browser의 디렉터리 노드 전달을 참조로 바꿔 불필요한 복사를 줄였습니다.

### FBX 본 계층과 애니메이션 보정

- 스킨이 없는 메시가 본 애니메이션에서 떨어지는 문제에 대응해 연결할 본을 현재 노드·자손·조상 순으로 찾고, 강체 가중치와 바인드 포즈 보정을 적용했습니다.
- FBX의 Null/Wrapper 노드를 가짜 본으로 삽입하지 않고, 해당 노드의 바인드·애니메이션 변환을 실제 루트 본에 반영했습니다. CPU·GPU가 같은 역바인드 행렬을 사용하도록 맞추고, 루트 본의 불필요한 수평 이동도 보정했습니다.
- 메시 에디터에서 수정한 본의 로컬 기본 포즈에 애니메이션의 상대 변환을 다시 적용해 편집 결과와 재생 결과가 이어지도록 했습니다.

### 게임플레이와 에디터 조작

- 공격 애니메이션의 Notify 구간에서 본 위치를 기준으로 타격 범위를 계산하고, 구체와 대상 바운드의 교차를 검사했습니다. 같은 공격 구간에서 중복 타격을 막고, 피격 시 액터별 짧은 HitStop을 적용했습니다.
- 여러 액터를 선택했을 때 중심 위치에 기즈모를 놓고 함께 이동하도록 했습니다. 복제 액터의 이름이 겹치지 않도록 생성 규칙도 보완했습니다.

## 문제 → 적용 방법 → 결과 → 개선 방향

| 문제 | 적용 방법 | 결과 | 개선 방향 |
|---|---|---|---|
| CPU 스키닝만으로는 정점 처리 비용을 분리해 보기 어려움 | 버텍스 셰이더의 GPU 스키닝과 CPU/GPU 전환, 경로별 프로파일링 | 두 스키닝 경로를 선택·관찰하고 그림자 패스까지 일관되게 적용 | 동일 장면·모델에서 정량 성능 비교 |
| FBX 래퍼 노드와 비 스킨 메시 때문에 얼굴·소품이 본에서 분리됨 | 연결 본 탐색, 강체 가중치, 바인드 보정, 래퍼 변환의 루트 본 반영 | 실제 본 계층을 유지하면서 메시와 애니메이션 변환을 연결 | 다양한 FBX 계층 구조의 회귀 사례 축적 |
| 본 가중치와 스키닝 오류를 화면에서 파악하기 어려움 | 선택 본 가중치 히트맵과 CPU/GPU 통계 오버레이 | 영향을 받는 정점과 처리 경로를 에디터에서 확인 | 가중치 분포의 수치·범례 표시 개선 |
| 공격 애니메이션과 실제 타격 시점이 어긋남 | Notify 타격 구간, 구체–AABB 판정, 중복 타격 방지와 로컬 HitStop | 애니메이션 구간에 맞춰 충돌·피격 반응을 연결 | 무기 형태에 맞는 충돌 형상과 타격 우선순위 확장 |

## 빌드와 실행

Windows에서 Visual Studio 2022 C++ 워크로드, Windows SDK, MSVC v143으로 `Project/KraftonEngine.sln`의 `Release | x64` 구성을 빌드합니다. 프로젝트의 FBX SDK·FMOD·Lua 등 서드파티 의존성과 NuGet 패키지가 필요합니다. 실행 시 작업 디렉터리는 `Project/KraftonEngine`으로 설정합니다.

## 회고

스켈레탈 메시가 한 화면에서 정상적으로 보여도 CPU·GPU 스키닝, 그림자, 애니메이션 재생은 서로 다른 경로에서 같은 본 데이터를 해석합니다. 변환 공간을 통일하고 가중치와 실행 시간을 눈으로 확인할 수 있게 하면서, 렌더링 기능을 만들 때 관찰 도구와 예외 사례를 함께 준비해야 한다는 점을 배웠습니다.
